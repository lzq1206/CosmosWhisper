# CosmosWhisper · 可见天区

可见天区版以 CosmosWhisper 城市页面截图作为完整底图，并按设备位置选择最近城市。

截图在网页画布加载后等待 5 秒再生成，按设备像素导出 1024×1024 高分辨率底图。大尺寸另生成适配竖向组件的扩展底图，通过增加同色背景铺满组件且不拉伸或裁切圆形星盘。可见天区的大尺寸会在绘制前缓冲图片数据，降低 WidgetKit 截图时远程图片未完成加载的概率。GitHub Actions 每 15 分钟更新一次城市图片。小尺寸方形组件填满显示；中尺寸等比适配且保留完整星盘。小组件只显示星盘底图，不叠加指针或数字时间。

小组件需要定位和网络权限。定位结果会匹配仓库内最近的城市页面；网络权限用于读取该城市的截图。系统实际刷新小组件的时间由 ScriptWidget 和 WidgetKit 管理。

导入文件：scriptwidget/exports/visible-sky.swt
